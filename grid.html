Divisão de Elementos em Linhas e Colunas

O CSS Grid é um sistema de layout bidimensional, o que significa que ele lida com colunas e linhas simultaneamente. É a ferramenta ideal para estruturar a página inteira ou criar layouts complexos.

  • display: grid;: Ativa o modo grid no container pai.
  • grid-template-columns: Define o número e a largura das colunas. A unidade fr (fração) ajuda a dividir o espaço de forma proporcional.
  • grid-template-rows: Define a altura das linhas no layout.
  • gap: Cria um espaçamento uniforme entre as células da grade.
